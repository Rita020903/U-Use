# A4 个人独立反思：正式要求

2026-10-20 根据正式 brief 第 23–29、31 页更新。每人独立完成、独立提交，旧角色文件是取材提示，不是可直接提交的本人反思。

| 要求 | 内容 |
| --- | --- |
| 权重 | 30% |
| 截止 | 2027-04-16，具体时刻以门户为准 |
| 长度与格式 | 1,500–2,000 英文词（words），Word .docx，个人经 LMO 提交 |
| 学术来源 | 至少三项学术参考文献，APA 7 文内引用与参考表 |
| 方法 | Gibbs 或其他认可反思模型，帮助分析而非流水账 |
| 行动 | 至少三个具体、可执行、有完成证据的后续承诺 |

## 四个明确主题

1. 创业学习与技能发展：哪些能力变化，具体经历如何推动变化。
2. 团队动态与协作：本人真实角色，至少一次团队紧张或挑战，如何处理、以后如何改。
3. 创业思维与身份：用至少一个创业理论或模型解释自己的经验，不只复述理论。
4. 未来行动与成长：至少三个从自身证据导出的行动，说明场景和完成标准。

评分为反思深度 35、学习证据 30、创业思维 20、学术写作 15。第一人称、具体日期、真实个人行动和产出，清楚区分队友及 AI 的贡献；失败、误判、冲突和未完成事项同样可以成为证据，不能虚构情绪、反馈或经历。

导师只能澄清主题、格式和反思方法，**不得阅读、修改或评价反思正文草稿**。不要安排统一代写、导师润色正文或组员互换同一份成稿。每个人自行负责独立性、参考文献准确性和允许范围内的 AI 声明。
