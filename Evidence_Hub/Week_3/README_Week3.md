## Session 前 checklist

- [x] `待填` 全部补齐（`W3_Market_Sizing_v1.md` 已无待填）。
- [ ] workbook 的渠道表已换成**你们真实的**群数和人数（现在填的是合理默认值，session 前换掉）。
- [ ] 每个市场数字都能指到 `W3_Evidence_Sources.csv` 里的一个证据 ID。
- [x] 竞品表里 6 个是**点名的、当前在运营的**竞品或替代方案，并附来源（C01-C06）。
- [ ] 竞品截图带日期，个人信息打码（4 张，见「截图清单」页）。

- [ ] 每个组员都能不看稿子解释：公式、单位、来源、假设。
- [ ] session 后用同一流程另存 `_v2`，并在 Weekly Log 记录改了什么、为什么。
