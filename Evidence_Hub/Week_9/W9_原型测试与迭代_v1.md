## 1. 测试前 10 分钟准备（Rita）

```
cd xjtlu-market-app
npm install
npm run reset     # 恢复 14 件演示物品，保证演示时列表不为空
npm run start     # 学生端 http://localhost:3000，管理端 http://localhost:3000/admin
```

演示路线固定成一条：搜索「计算器」→ 筛选「可借」→ 打开详情 → 点预约 → 看管理端。**不要现场换路线。**

## 2. 测试任务卡（照这个问，不要演示给用户看）

| # | 任务 | 观察什么 | 合格标准 |
|---|---|---|---|
| 1 | 「找一下这周五考试要用的计算器，要求可以借」 | 会不会用搜索 + 筛选；花多久 | 60 秒内找到 |
| 2 | 「看一下这件东西，决定要不要预约」 | 有没有注意到押金、可用时间、归还规则 | 能说出其中 2 项 |
| 3 | 「如果想跨校区借，你会怎么做」 | 能否理解本校区优先 / 跨校区开关、公共交付点 | 能说清交付点在哪 |
| 4 | 「你想把自己的东西放上去吗」 | 愿意开放什么、选哪种方式、最大顾虑 | 能说出 1 个顾虑 |

记录用 `17_用户测试记录模板.md`，归档为 `Week_9/W09_PrototypeTest_T0x_日期.md`。

**测试三条纪律**：不提示（用户卡住先等 10 秒）；不解释（先记录他的误解）；不辩护（听到批评只说「谢谢，我记下来」）。
