## Week 4-14 每周都有成品文件（直接照做即可）

Week 3 之后的每一周，Evidence Hub 里都已经放好一份**写好结构的成品文件**：当周要求、导师会检查什么、「已经替你做好什么」、「你只剩哪几件事」、责任到人、红线。组员只需要按当周文件执行并在 Weekly Log 填空。

> 每周的 Weekly Log 填空模板在 `01_Weekly_Log/Weekly_Log_Week4-14_骨架_可直接粘贴.txt`；当周内容直接复制粘贴、填掉【填】即可。

## 命名规范（课程要求）

- 带版本号：`W3_Market_Sizing_v1`，修改后另存 `W3_Market_Sizing_v2`。
- 不覆盖旧版本；改动写进文件末尾的版本记录表 + Weekly Log。
- 截图带日期：`W3_Competitor_C01_Xianyu_2026-09-25.png`。
- 访谈匿名编号：`W05_UserInterview_U01_2026-10-15.md`。

## 上线前必做（把本地文件夹变成真正的 Evidence Hub）

1. 选一个在线共享位置（OneDrive / SharePoint / Google Drive / 腾讯文档共享文件夹任一）。
2. 按上面的目录结构建好，把文件传上去。
3. 给 **supervisor** 和需要的组员开编辑/查看权限。
4. 自己用一个非组员账号或浏览器无痕模式打开一次，确认权限真的能用。
5. 截图权限设置页，存入 `Week_1/` 作为证据。

## 注意

- 本地这份文件夹是工作副本，supervisor 看不到本地文件，**必须上传到在线共享位置才算完成**。
- Weekly Log 不使用 Excel；Evidence Hub 里的表格可以用表格，但 Weekly Log 必须是可共享的在线文档。
