## 真实证据怎么存

- 使用匿名 ID、实际日期和版本，例如 W05_Interview_R01_20261015_v1；实际没有发生的记录不预填。
- 主张注明来源和证据 ID，区分原始记录、清理副本、分析、假设与反例。原始记录保留只读副本。
- 提交文件、上传时间和回执分别核验；代码进入 GitHub 不等于课程门户已经提交。
- 个人信息、联系名单、同意签名、录音、完整课表、私人反馈、A4 正文、成绩和回执存入有访问控制的私有共享位置，不放公开 GitHub。
- 私有共享位置须按课程要求给 supervisor 和组员开权限，并实际验证能打开。公共仓库仅放经人工检查的安全模板、去标识材料与状态。
