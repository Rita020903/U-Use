## 2. 原始证据怎么存（导师会抽查 2 条）

每条证据必须带齐 6 项，缺一项就算不合格：

1. 匿名编号（U0x / T0x）
2. 日期
3. 校区（SIP / 太仓）
4. 样本类型（熟人 / 非熟人）
5. 同意方式（口头同意 + 日期）
6. 原话或操作观察（不要只写总结）

文件命名：`W05_UserInterview_U01_2026-10-15.md`、`W05_PrototypeTest_T01_2026-10-16.md`。

## 3. Interim Pattern Summary（中间小结，谨慎措辞）

写完 5 条证据后，填下面这张表（**只写证据支持的，不要下大结论**）：

| 观察到的模式 | 支持证据 | 相反证据 | 谨慎表述 |
|---|---|---|---|
| 例：多数受访者提到「考试/活动临时用一下」 | U01、U02 | 待填 | "2/3 的受访者提到……（样本很小，仅作初步观察）" |
| | | | |
| | | | |

可以用的措辞：*early validation suggests* / *2 of 3 interviewees mentioned* / *this needs to be confirmed with a larger sample*。
不能用的措辞：*students want this* / *the market needs U Use* / *we have proved*。
