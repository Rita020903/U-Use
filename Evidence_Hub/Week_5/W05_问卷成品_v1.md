## 题目（15 题，选项顺序照抄）

**Q1（单选）你主要在哪个校区？**
SIP / 太仓 / 两个校区都经常去

**Q2（单选）你现在是？**
本科一年级 / 本科二年级 / 本科三年级 / 本科四年级 / 研究生 / 其他

**Q3（单选）过去一个学期，你有没有临时需要过某件东西，但不想专门买新的？**
经常（每月都有）/ 偶尔（一学期 2-3 次）/ 很少（一学期 1 次）/ 没有

**Q4（多选）你临时需要过哪些东西？**
考试计算器 / 正装或礼服 / 行李箱 / 自行车或头盔 / 投影仪、音响等活动设备 / 转换插头或工具 / 数码配件 / 教材或复习资料 / 其他（请填写）

**Q5（单选）如果只需要用 1-7 天，你更倾向于？**
向同学借 / 短租 / 买二手 / 买新的 / 不解决、放弃

**Q6（单选）你愿意把自己闲置的东西开放给其他西浦同学使用吗？**
愿意借出 / 愿意短租 / 只愿意卖掉 / 只愿意交换 / 不愿意

**Q7（多选）哪些机制会让你更愿意借用或短租？**
西浦学生邮箱认证 / 借出前拍照确认状态 / 归还时双方确认 / 押金记录 / 举报与管理端介入 / 公共交付点 / 借用协议模板

**Q8（单选）对于价值 100-300 元的物品，你能接受多少押金？**
不接受押金 / 20 元以内 / 20-50 元 / 50-100 元 / 100 元以上，看物品价值

**Q9（多选）借用别人的东西，你最担心什么？**
对方不归还 / 物品损坏说不清 / 押金退还纠纷 / 见面地点不安全 / 跨校区太麻烦 / 信息不真实

**Q10（单选）你愿意使用另一个校区同学开放的物品吗？**
愿意，只要物品值得 / 可能愿意，看交付地点 / 不太愿意 / 完全不愿意

**Q11（单选）跨校区交付你更能接受哪里？**
校车点 / 图书馆门口 / 学生中心 / 宿舍区附近 / 只接受本校区

**Q12（单选）看完这句描述后，你能理解它和闲鱼/微信群的区别吗？**
「U Use 是西浦学生邮箱认证的校内物品使用平台，可以按你想用的时间段买断、借用、短租或交换，押金、归还确认和公共交付点都在流程里。」
非常清楚 / 大致清楚 / 不太清楚 / 完全不清楚

**Q13（多选）你最想用哪个功能？**
搜索附近可用物品 / 借用 / 短租 / 买断 / 交换 / 跨校区预约 / 押金与归还确认
