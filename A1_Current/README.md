## 市场与经营口径

学校官网中英文Overview均公布26,000+在校学生，标注更新于2026年5月。它是大学整体报告口径，不是XEC单校区人数或付费人数。以N=26,000作可复算的保守基数，不把加号数据说成精确学籍或最高上限。

四周可服务需求公式：SAM=N×c×d。其中c为能在SIP/XEC参加线下交付的比例，d为其中四周内有既有渠道无法满足的计划性物品需求者比例。演示情景c=80%、d=1%，得到208人。两个比例均明确为规划假设，不来自15人定性摘要，也不是市场需求已被验证或预计必然采用。

八个DTS班约430人是Rita说明的初始渠道。试点活动独立计算：80邀请×10%发布=8请求；min(8×25%完成、4物主×2次容量)=2次完成。学生人数、请求和交易次数不混用。后续SIP/XEC推广仍是计划，不声称已覆盖全校或测得增长。

BMC保留九模块、免费试点、180元四周预算及20元GMV/0元费收入/−180元现金结果。后期5%收费情景下0.30元/总完成、334次/月现金门槛，仍是条件计算而非利润或需求预测。学校人数和208人情景不直接推算收入。
