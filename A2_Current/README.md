# A2 当前录制准备

版本：2026-10-20，依据正式 CW brief 第 13–17 页。这里是制作准备，不是已完成的视频或课程提交。

| 文件 | 用途 |
| --- | --- |
| [英文录制稿](A2_Recording_Script.md) | 约 5 分 25 秒的七人分段、画面和讲述；时长为排练目标，需实测 |
| [录制稿 PDF](UUse_A2_Recording_Script.pdf) | 同版可读预览，方便排练；不是 MP4 成片 |
| [制作与证据指南](Production_and_Evidence.md) | 五项差异化的核实方法、主张证据图、资金用途、路线图和导出/双提交检查 |
| [财务模型](UUse_A2_Financial_Model.xlsx) | 六个月 Base/Downside 单一联动模型、资金与盈亏平衡；所有预测均标为假设 |

最终要交的是一个英文 MP4，3–6 分钟、不超过 500 MB，2026-12-18 截止；具体时刻待门户确认。同一批准文件交 LMO 和 Dream Chaser，保留两个回执。鼓励成员出镜，不把鼓励写成七人强制露脸。

四项评分各 25 分：财务预测、竞品分析、进展与路线图、投资潜力。本版保留低使用量的定位，不编造增长或盈利。基准六个月 38 次完成是情景，不是 38 名用户；预计平台费 CNY13、现金预算 CNY687.20、现金经营缺口 CNY674.20。该基准尚不支持股权投资回报叙述。

建议资金请求为 CNY900 的非稀释性验证经费，先 CNY200，第二阶段 CNY700 需真实试点复核与批准。团队未批准、未联系或未获得任何资金；录制前必须核实请求金额和用途。当前模型的 5% 后期费率、付费意愿及成本也未验证。

A1 仍使用 [当前六页主稿](../A1_Current/README.md)。旧 26,000 人、120 次邀请、7 次交易、CNY216 GMV 等口径不再用于当前脚本。正式要求和仍需提供的材料见 [课程总控](../Coursework_Requirements_20261020.md)。
