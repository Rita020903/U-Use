# U Use 小组访谈与用户测试示例

给组员看的练习材料：15份虚拟访谈，以及100名虚拟用户的500条合成任务记录。用来理解访谈写法、主题编码、任务测试和统计口径。

**所有人物、经历、回答、用时和结果均为AI构造的虚构示例。没有真实招募、访谈或用户测试；100人是模拟规模，不是实际参与人数。这些文件不属于正式研究证据，不应作为真实结果提交。**

编制日期：2026-10-07。文件名中的 `SYNTHETIC` 就是“合成、虚构”的意思。

## 推荐阅读顺序

1. 先看本页，弄清楚每个文件是什么。
2. 阅读 [15份访谈示例](SYNTHETIC_15_Interviews.md) 的前3份，了解如何从回答整理主题，同时保留反例。
3. 下载 [Excel工作簿](SYNTHETIC_100_User_Test_Examples.xlsx)，先看“示例汇总”，再查看逐条任务记录。
4. 阅读 [详细说明与练习](START_HERE_SYNTHETIC.md)，讨论哪些问题值得通过真实研究验证。

Markdown文件可以直接在GitHub上阅读。Excel请打开文件页面，使用下载按钮保存到本机，再用Excel或WPS打开。CSV适合筛选和重新统计，不需要写代码才能阅读。

## Excel四张表怎么读

| 工作表 | 一行表示什么 | 重点 |
|---|---|---|
| 示例汇总 | 一项任务或一项合成计数 | 通过公式读取其他表；不是实际产品表现 |
| 虚拟用户100 | 一个虚拟用户 | V001至V100只是示例编号，不是实际学生编号 |
| 任务示例500 | 一个虚拟用户的一项任务 | 包含结果、假设用时、完成编码、示例错误和反馈 |
| 访谈索引15 | 一份虚构访谈 | 与访谈文本及用户表中的V001至V015对应 |

15份访谈是100个虚拟画像中的前15个，不是另加15人，因此不能算成115人。XEC表示太仓校区，SIP表示苏州工业园区校区；55 XEC和45 SIP只是示例配额，不代表学校真实人群构成。

## 五项任务与结果含义

合成任务分别是：按日期找物品、求物与推荐、费用与归还、不开GPS约地点、课表校对与匹配。最后一项假设每个人导入并校对自己的课表，不表示全校使用同一份示例课表，也不衡量OCR识别准确率。

| 结果 | 含义 | 是否计入尝试人数 |
|---|---|---|
| 独立完成 | 在合成情境里，无主持人帮助完成任务 | 是 |
| 协助完成 | 在合成情境里，得到帮助后完成任务 | 是，但不算独立完成 |
| 未完成 | 在合成情境里，尝试后仍未完成 | 是 |
| 未尝试 | 没有尝试这项任务，用时留空 | 否 |

100个虚拟用户共分配500条任务记录，其中472条是合成尝试，28条未尝试。课表任务的独立完成率为39/72，约54.2%，不是39/100。未尝试的时间不是0秒；未完成记录的用时是预设停止上限，不是完成时间。

“完成编码”中，独立完成和协助完成为1，其他为0。“独立编码”仅独立完成为1。不要只看完成编码就宣称用户可以独立完成。

## 如何讨论产品

这些例子刻意包含低频需要、熟人渠道更方便、押金疑虑、物主不愿出借和隐私顾虑，不设定人人都想使用产品。可以据此练习提出待验证问题，不能推算真实市场规模、定位接受率、需求、满意度、营收或留存。

合适的讨论：“在这套虚构情境里，一些回答担心费用和归还责任。真实测试可以观察参与者是否能正确解释押金和归还条件。”

不合适的结论：“我们已经访谈15人、测试100人，证明产品受欢迎。”

## 修改与正式研究

编辑Excel时，汇总公式会随原始工作表变化；CSV和访谈文本不会自动同步。修改后应检查人数、编号和口径，重新导出CSV并重新打包，避免不同文件出现不同版本。

保留每行的 `SYNTHETIC 虚构示例` 标注。真实研究应使用另一套记录文件和独立编号，记录真实同意、日期、实际操作与匿名原始材料，不要覆盖本目录或将合成记录混入正式证据。
