# 汤鋆秋的任务与资料

你的主责是迭代决策与验收。版本2026-10-07。职责来自Rita确认，课程要求来自所附手册，日期来自所附校历。任务卡是计划，不是已完成证据；任何勾选需有实际记录。内部数量/彩排/提前上传目标不是官方评分配额。

## 拿到目录先做什么

1. 读 [个人职责与交接](个人职责与交接.md) 和 [本周S1 Week 4任务](每周任务/S1_W04.md)。
2. 接收访谈/测试计划，建立问题ID、严重度和验收条件；与Rita约定本周范围；为不用定位、缺货和个性化课表准备风险清单。
3. 读 [课程要求](共同规则/课程评分与提交要求.md)，检查自己的A4独立责任和全组十项作业提交单元。
4. 本周按任务卡提交真实产出，记录个人贡献；未发生的工作保持未完成。

资料、共同规则和模板均在本目录，不需要先取得别人目录才能阅读。课程手册/校历在“资料/课程依据”；旧工作草稿在“资料/现有草稿”，合成材料在“资料/AI合成例子_仅练习”。
