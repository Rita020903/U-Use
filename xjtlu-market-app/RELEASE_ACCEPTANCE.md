# 工程验收与封版结论

验收窗口：2026-10-18 至 2026-10-19。范围为课程演示和下一阶段用户验证，不是公开上线认证。测试使用隔离生产构建、临时数据库、本机 SMTP 模拟器及虚拟测试账号，没有改动工作数据库，也没有向真实学生发送邮件。

## 结论

**可以功能封版，进入文档、assignment、演示录制和真实用户验证阶段。** 本轮发现的两项问题已修复，相关回归和同输入浏览器复测通过。在以下已执行的范围内，没有遗留阻断课程演示的问题；这不等于所有设备、文件或线上环境永远没有缺陷。

停止增加新功能和大规模重构。后续只修实际观察到的登录、交易、权限、隐私、数据保存、课表或演示问题。截图、录屏和作业中的产品描述使用同一个验收版本；有影响行为的新改动必须重测。

## 本轮修复

| 问题 | 复现 | 修复与复测 |
| --- | --- | --- |
| 无标签的独立教室代码丢失 | 三列 PDF 的 `CB-301` 没有 `Room:` 前缀，原解析结果为空 | 保留独立一行的短楼宇代码与房间号；不因此猜测校区。教室行位于中文课程名前时也不再充当课程名。新增失败用例后修复，同一 PDF 重导入，得到 `CB-301`，星期、时间和课程数保持正确 |
| OCR 命令可能造成错误的通过判断 | 不带图片执行 `test:ocr`，旧命令只跑解析测试却仍成功退出 | 命令增加必需截图检查。缺少输入时退出码为 1，且没有 PASS；加入自动回归。提供原七课程截图后实际 OCR 通过 |

## 实际浏览器验收

本机无头 Chrome 启动受执行环境限制，因此改用内置浏览器逐项操作。没有把启动失败说成 Playwright 全自动端到端通过。下列结果来自实际页面、可见状态、导出文件与截图。360、390、768、1280 像素是响应式视口检查，不等于持有四种实体设备。

| 场景 | 已观察到的结果 |
| --- | --- |
| 两个独立账号登录 | 两个浏览器来源分别通过实际验证码表单登录，验证码来自本机模拟 SMTP；显示正确账号 |
| 发布和审核 | 上传测试照片、设置租金/押金/可用日期、选择 XEC 的 A 栋公共入口，提交后进入审核，通过后买家可见 |
| 预约与费用 | 手机视口手动预约成功，租金 3.50 元、押金 20 元与预约记录一致；不要求定位或课表 |
| 双方交付与归还 | 待确认、已确认、使用中、待归还、已归还按双方实际操作流转；单方操作不冒充双方确认 |
| 交易消息与线下款项记录 | 双方在对应交易中看到发送的消息，各自确认线下款项，页面显示双方已确认；没有实际付款或托管 |
| 求物与推荐 | 发布需求，物主看到符合条件的物品并发送推荐，求物者看到私有推荐；没有自动产生预约，标记解决后退出公开有效列表 |
| 三种课表输入 | 原 JPG 提取七条课程；三列周一/周三/周六 PDF 提取三条；文字型周二/周日 PDF 提取两条，并正确追加为五条 |
| 课程核对与保存 | 未核对不能启用；可以修正识别文字及教室、设置个人学期与整周假期，逐条确认后保存 |
| 草稿与账号隔离 | 新页面恢复七条未保存课程；另一账号仍是其自己的三条、随后五条课程；离开未保存草稿有可取消的提醒 |
| 双人课表匹配 | 两个账号分别启用不同课程后，预约页显示双方空档及具体时间地点；点击建议填写预约，仍需主动发送和物主接受 |
| 取消预约 | 在确认框点取消，预约保持待确认；明确确认后变为已取消 |
| 地图隐私与资源 | 首页默认折叠；展开后定位和分享均未开启，分享框不可用；XEC 与 SIP 官方地图均实际加载，切换校区后地图收起 |
| 导出与退出 | 下载包含本人七条课程、不含原始 OCR 或另一账号邮箱；退出后回到访客、课程清空，另一标签页不再显示旧私有身份 |
| 排版与错误 | 在上述视口抽查首页、交易、课表和地图，无文档横向溢出；两个操作账号的浏览器错误日志未报告运行异常 |

浏览器中的买断、交换和注销全流程没有再次逐屏执行，它们由本轮 API/业务测试覆盖。真实截图存在字形识别差异，已经实际验证手动校对路径；不承诺所有版式自动识别百分之百准确。

## 公开开放前仍需完成

- 实际学校邮箱送达、发件域和生产 SMTP 验证。
- HTTPS、项目自有生产数据库、定时维护、监控及生产备份恢复演练。
- 实体手机、Safari/其他浏览器矩阵、两校区实际网络与 GPS 权限场景验收。本轮未申请真实位置权限。
- 运营联系人、数据保留和争议责任落实，开放前的独立安全与合规审查。

这些事项不要求重新增加产品亮点，但不能用课程演示验收替代。测试账号、模拟商品与工程操作次数不计入真实访谈、用户测试样本或成交数据。个人课表、导出文件、账号验证码及完整私有截图不上传公开仓库。
