# U Use

西浦 SIP / XEC 双校区物品交易应用。XEC 为西浦创业家学院（太仓）；内部校区键保留 `TAICANG`，兼容已有课表和交易数据。买断、借用、短租与永久交换共用一套身份、审核、预约、交付、归还和争议流程。产品功能不限制某一专业、年级或一份课表；商业需求和真实使用人数仍需要实际验证。

## 产品亮点

- **按使用日期找物品**：无需导入课表或开启定位，按日期筛选覆盖使用周期、未被预约占用的物品。买断按交付开始日期判断；筛选结果不是预约确认，提交预约时仍会再次校验。
- **求物板**：发布物品、日期、方式与可选预算；同学只能推荐自己已审核且符合日期、校区和预算的物品。推荐不等于预约，求物者查看物品后走现有交易流程。推荐仅求物者和推荐者可见；已解决、撤回或过期的需求不在公共列表展示。

- **地图按需使用**：首页默认折叠，未展开不加载地图底图。GPS、位置分享均须主动开启，地图折叠后停止定位并撤回分享（失败时由 2 分钟 TTL 兜底）。发布地点名称必填，公共点坐标可选；不把实时位置作为交易资格或产品主卖点。

借用和短租需覆盖整个求物周期；买断可以在需求的交付日期窗口内选择一天，不要求只能在第一天交付。推荐列表与已收到推荐的可用状态都从服务器重新检查预约占用。

## 本地运行

需要 **Node.js 24**。

```bash
npm ci
cp .env.example .env.local
```

在 `.env.local` 设置自己的 `ADMIN_PASSWORD`、`AUTH_SECRET`。真实登录需要 `SMTP_URL` 和 `SMTP_FROM`；仅本机开发可设置 `AUTH_DELIVERY=local`，页面会明确展示开发验证码。正式模式忽略此选项，开发账号不能参与正式交易。

```bash
# 可选：仅首次导入旧物品和已有私人课表。
MIGRATE_LEGACY=true npm run dev -- --port 3006
```

学生端：<http://localhost:3006/>。后台：<http://localhost:3006/admin>，用户名 `admin`。不设置 `MIGRATE_LEGACY` / `SEED_DEMO` 时，新数据库从空白开始。旧 JSON 只用于显式导入，不再作为运行时数据库。示例物品会标记为演示，不能冒充真实发布者进行预约；日期也不会自动顺延。

## 完整流程

- 学生邮箱验证码登录，账号绑定自己的发布、课表、交易、消息和通知。
- 发布 1–5 张实物照片，标记公共交付点，填写可用日期、费用和规则；后台审核后展示。
- 本人修改或下架发布。有进行中的交易时禁止修改合同相关信息；修改后重新审核。
- 预约绑定双方身份、具体时间地点、租金和押金快照；租金不足 24 小时按一天，永久交换必须绑定本人已审核的交换物品。
- 同一事务检查物品、交换物品、双方课程和双方其他交付/归还安排。未确认预约在 24 小时或交付开始前自动释放；物品逾期未归还时禁止继续预订。
- 发布者接受或拒绝；双方可在交付前取消，分别确认实物交付和归还。买断/交换完成后物品下架。
- 交易双方专属消息、站内通知、可重试邮件发件箱；双方可发起争议，管理员仲裁并留下审计记录。
- 金额是**线下结算约定和确认记录**，不是支付、托管或退款服务。

## 每个人独立的课表

截图 JPG / PNG / WebP、PDF（最多 10 页、15 MB）、课程文字、手动补录均可进入同一校对流程。文件在浏览器处理，不上传原图、PDF 或教师姓名。Tesseract.js 中英文语言包、PDF.js worker 和资源由本机静态路径提供。

课程数量、名称、星期、授课周次、教室代码和学期起点不预设。每个人设置自己的第 1 周周一、学期结束日期，可填写单双周、全校/单课停课日期、实际补课日期和已确认的下课出口。截图里的 AB / BC / CD 只保留为原始教室代码，不臆造为公共入口。

导入结果全部为**待核对**。无法可靠提取的星期、时间或周次须人工补充，逐条确认后才允许启用。模糊、无规则、多栏或特殊课表不能保证全自动识别；可看原图和原文修正，不把识别置信度当作正确性保证。草稿按账号保留在当前浏览器，离开时提醒；服务器只保存确认后的必要字段。

推荐寻找未来 14 天 09:00–20:00 的 15 分钟交付窗口，并同时检查归还窗口、租借长度、可用日期、双方课程和其他交易。保留发布者约定的校内或**校外**公共交付点；跨校区建议须本人同意。只有双方提供课表才显示共同空档，不等于双方已经接受预约。未知或超出课表覆盖范围的日期不会默认为全天空闲。

基础 15 分钟、不同楼宇 25 分钟、跨校区 90 分钟是可解释的保守缓冲，不是学校校车时刻或实际路程保证。

## 地图与位置隐私

Leaflet / OpenStreetMap 提供交互底图，学校官方地图提供楼宇对照。用户主动点击定位才调用浏览器定位，精确坐标仅留在当前页面。公共物品交付点由发布者主动标记，不是住宿位置或私有实时坐标。

分享默认关闭。开启后服务端只保存约 200 米网格（0.002 度，大小随纬度变化），按登录用户、当前校区、5 公里查询范围、2 分钟有效期过滤。不显示未分享或虚构的在线用户。每个页面有独立分享租约；停止、退出或离开地图撤回，网络失败时清理旧标记。GPS 和地图依赖设备、权限、网络，服务器不声称能证明客户端的实际物理位置。

XEC 采用 A–G 栋等实际命名，公寓明确标为校外；公共入口和开放条件须双方再次确认。导航按校园与地点名称搜索，不混用 WGS84 / GCJ-02 坐标。

## 数据与部署

开发默认 SQLite，WAL、完整同步、跨进程事务锁；私有目录和文件限权。多个应用实例使用 `DATABASE_URL` 连接 PostgreSQL，预约读取、冲突检查和写入在同一事务和数据库级锁内。服务器不依赖进程内数组维护真实数据。

正式启动必须设置 `DATABASE_URL`，或在**持久磁盘单机**上显式设置 `ALLOW_LOCAL_DATABASE=true`。不能把本地 SQLite 放在会被销毁的 Serverless 文件系统。当前 PostgreSQL 使用按记录类型分组的事务记录表，应用层维护业务约束；没有宣称独立关系表、RLS 或无限吞吐量。后续高流量扩展需按负载测试结果细化索引与锁粒度。

实物照片自动旋转、缩放、转为 WebP 并去除 EXIF，保存在数据库；未审核照片仅本人和管理员可访问，已审核发布照片可公开查看。定时维护清理过期会话、验证码、位置、限流记录、长期未引用照片和已读旧通知。交易与消息不在没有明确保留政策时自动删除。

详细上线配置、备份和隐私边界见 [部署说明](DEPLOYMENT.md)。旧 `supabase/schema.sql` 是历史草稿，**不能作为当前应用迁移脚本执行**。

## 稳定性与恢复

- 物品、求物、预约和交易消息使用按账号隔离的提交标识，同内容重试返回原记录，不重复创建或重复通知；修改内容后生成新标识。预约重试返回原预约的当前状态，包括已取消或完成，不重新占用物品。客户端不自动重试有副作用的请求；网络异常时先查看历史记录。
- 账号切换会撤销旧请求结果并清空私有视图；私有请求还携带页面所属账号，服务端与 Cookie 身份核对，不一致拒绝执行。该请求头不是身份凭证。支持 BroadcastChannel 的浏览器会同步其他标签页，页面再次获得焦点时也检查身份。收藏、物品、求物、消息和课表草稿按账号隔离。
- 求物草稿支持离开后恢复；损坏草稿不能直接进入页面。退出成功不依赖浏览器存储可用性；若本机清理失败会明确提醒，共用设备需手动清除本站存储。
- 业务网络请求含响应正文均设 30 秒超时；分页失败保留已有物品并可重试。重要操作统一使用支持键盘取消的页面确认弹窗；页面错误和不存在的链接有恢复入口。
- 交易、消息和通知定时刷新等待上一请求完成；刷新预约不卸载已打开的会话。发送成功与后续刷新失败分别显示，消息按稳定游标分批加载历史，保留阅读位置和本机未发草稿。通知已读仅更新服务器确认的记录。
- 预约严格校验真实日历日期、时分秒与时区，不接受自动顺延的非法日期；课表尚未成功加载时禁止编辑和保存空白数据，并提供重试入口。
