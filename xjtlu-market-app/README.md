# U Use App

面向西交利物浦大学学生的物品使用平台原型。它不是单纯的校园版闲鱼，而是把学生的临时使用需求产品化：买断、借用、短租和交换都可以在同一个微信 H5 / Web App 中完成。

## 当前功能

- 学生端：首页发现可用物品，支持校区切换、搜索、分类筛选、使用方式筛选。
- 校园地图：展示 SIP / 太仓校区附近可用物品与公共交付点，定位开启后支持就近推荐。
- 使用方式：买断、借用、短租、交换。
- 物品详情：展示押金、租金、可用时间、归还规则、借还协议。
- 发布物品：填写可用日期、使用方式、押金、租金、交付地点和跨校区借还。
- 借还预约：模拟借出时间、归还说明和公共交付点确认。
- 安全反馈：举报物品或聊天内容。
- 管理端：物品审核、认证用户、借还记录、押金争议和举报处理的看板原型。

## 项目定位

U Use 的核心洞察是：学生很多时候并不想拥有一件物品，只是短期需要使用它。例如考试计算器、答辩正装、行李箱、自行车、投影仪、活动设备和转换插头。普通二手平台解决的是“买卖”，U Use 解决的是“什么时候、在哪里、安全地用到它，并按约归还”。

## 为什么不容易和其他小组重复

- 不以回收、环保或可持续为主叙事，避免和校园回收项目重复。
- 不只是二手交易列表，而是“使用权流转”：同一件物品可以被买、借、租或交换。
- 产品机制围绕可用时间、押金、借出前状态确认和归还确认设计。
- 双校区场景不是简单浏览另一个校区，而是通过公共交付点和校车点降低跨校区借还成本。

## 技术说明

- Framework: Next.js 14 App Router
- UI: React + CSS + lucide-react
- 数据：本地 JSON 文件模拟数据库
- 当前版本不接入真实支付、实名系统、短信、地图 SDK 或服务器。适合课程展示、交互原型和后续 vibe coding 迭代。
